# CIMS Deferred Enhancements

The following nine user-deferred feature areas are not implemented. They describe possible future scope only; no supporting routes, models, integrations, or deployment capabilities should be inferred from this list.

## 1. Advanced Anomaly Detection

Develop behavioral baselines and detection models that identify unusual patterns across security telemetry and incident activity beyond the current stored-log filtering capabilities.

## 2. NLP-Based Text-to-SQL

Allow authorized users to express reporting questions in natural language and translate them into validated, read-only, schema-constrained SQL queries.

## 3. Large Language Model Integration

Evaluate governed large language model assistance for case summarization, investigation context, and analyst-facing drafts while retaining human review of generated content.

## 4. Real-Time SIEM Integrations

Add production connectors that receive and normalize live events from external SIEM platforms rather than relying on manually submitted or seeded security-log documents.

## 5. Live Firewall Integrations

Connect approved firewall platforms so authorized operators can inspect current controls and perform explicitly confirmed rule operations through controlled integration adapters.

## 6. Automated Incident Response

Introduce policy-governed response playbooks that can execute approved containment and remediation steps with safeguards, execution tracking, and human oversight.

## 7. External Threat Intelligence API Integrations

Retrieve indicators and threat-actor context from selected external threat intelligence APIs and present provenance-aware enrichment for analyst review.

## 8. Distributed Deployment

Support coordinated deployment of the frontend, API, processing services, and data stores across multiple nodes or environments with defined scaling and configuration boundaries.

## 9. Advanced Predictive Analytics

Develop forecasting for incident trends, workload demand, severity patterns, and operational risk using evaluated historical-data models.
